# Genyu Xu · 许亘昱

Bilingual academic homepage / 中英双语学术主页

- Website: https://ennxu.com/
- English: https://ennxu.com/?lang=en
- GitHub profile: https://github.com/GenyuXu

The site presents research interests, 17 journal papers grouped by research topic, academic appointments, teaching, and professional contact information.

## Editing and hosting

GitHub Pages publishes the main branch from the repository root. The self-contained index.html includes the page content, styles, portrait, and Chinese/English translations; no build step or external font service is required. Edit the Chinese text and the matching English translation entries together. Paper titles and DOI links retain their original form, and years follow journal issue metadata.

The site does not include the original CV, private phone numbers, birth date, or student details. It has no third-party tracking; the language choice is stored locally in the visitor’s browser.
